# Chatbot Frontend User Guide

## Overview

The Chatbot Frontend is a modern Next.js-based interface that provides users with an interactive conversational experience. This guide will help you understand how to use the chatbot effectively.

## Getting Started

### Accessing the Chatbot

1. **Open your web browser** and navigate to the chatbot interface
2. **Wait for the interface to load** - you'll see the chat widget appear
3. **Start typing** your message in the input field at the bottom

### Basic Usage

#### Starting a Conversation

1. **Type your message** in the text input field
2. **Press Enter** or click the send button
3. **Wait for the bot response** - responses typically appear within 2-3 seconds

#### Message Types

The chatbot can handle various types of interactions:

- **Questions and Inquiries**: Ask specific questions about campus services
- **Support Requests**: Request help with academic or administrative issues
- **Information Retrieval**: Get information from the knowledge base
- **Ticket Creation**: Create support tickets for complex issues

## Features

### Real-time Chat

- **Instant messaging**: Messages are sent and received in real-time
- **Typing indicators**: See when the bot is processing your request
- **Message history**: Your conversation history is maintained during your session

### Smart Responses

- **AI-powered replies**: The bot uses advanced AI to understand your questions
- **Context awareness**: The bot remembers previous messages in your conversation
- **Knowledge base integration**: Access to comprehensive campus information

### Escalation to Human Support

When the bot cannot fully address your needs:

1. **Automatic detection**: The bot recognizes when human help is needed
2. **Ticket creation**: A support ticket is automatically created
3. **Agent assignment**: You'll be connected to an available support agent
4. **Seamless transition**: Continue the conversation with a human agent

## Common Use Cases

### Getting Campus Information

**Example conversation:**
```
You: What are the library hours?
Bot: The library is open Monday-Friday 8 AM to 10 PM, 
     Saturday-Sunday 10 AM to 6 PM. Would you like 
     information about specific library services?
```

### Requesting Support

**Example conversation:**
```
You: I can't access my student portal
Bot: I can help you with portal access issues. Let me 
     create a support ticket and connect you with our 
     technical team. What's your student ID?
```

### Course Registration Help

**Example conversation:**
```
You: How do I register for courses?
Bot: Course registration opens [date]. You can register 
     through the student portal. Would you like me to 
     guide you through the process or create a ticket 
     for registration assistance?
```

## Tips for Effective Use

### Writing Clear Messages

- **Be specific**: Instead of "help me", try "I need help with course registration"
- **Use keywords**: Include relevant terms like "transcript", "payment", "schedule"
- **Be conversational**: Write naturally, as you would to a human

### When to Escalate

The bot will automatically escalate to human support, but you can also request it:

- **Complex technical issues**: Problems requiring system access
- **Personal matters**: Issues requiring verification of identity
- **Urgent situations**: Time-sensitive problems
- **Dissatisfaction**: If the bot's response isn't helpful

### Privacy and Security

- **No sensitive information**: Avoid sharing passwords or social security numbers in chat
- **Secure escalation**: Personal information will be requested securely when escalated
- **Data protection**: Conversations are encrypted and protected

## Troubleshooting

### Chat Not Loading

1. **Refresh the page** - Sometimes a simple refresh resolves loading issues
2. **Check your internet connection** - Ensure you have a stable connection
3. **Clear browser cache** - Clear your browser's cache and cookies
4. **Try a different browser** - Test with Chrome, Firefox, or Safari

### Messages Not Sending

1. **Check connection status** - Look for connection indicators
2. **Wait a moment** - There might be a temporary delay
3. **Refresh and retry** - Reload the page and try again
4. **Contact support** - If issues persist, contact technical support

### Bot Not Responding

1. **Wait 10-15 seconds** - The bot might be processing a complex request
2. **Rephrase your message** - Try asking in a different way
3. **Use simpler language** - Break complex questions into parts
4. **Request human help** - Type "I need human assistance"

## Accessibility Features

### Keyboard Navigation

- **Tab navigation**: Navigate through chat elements using Tab key
- **Enter to send**: Press Enter to send messages
- **Escape to close**: Close modals or popups with Escape key

### Screen Reader Support

- **ARIA labels**: All interactive elements have proper labels
- **Semantic markup**: Properly structured HTML for screen readers
- **Alternative text**: Images and icons include descriptive text

### Visual Accessibility

- **High contrast mode**: Compatible with browser high contrast settings
- **Scalable text**: Text can be enlarged up to 200% without issues
- **Color indicators**: Information isn't conveyed by color alone
